# 本地化智能文件管理系统

## 项目介绍

这是一个功能强大的本地化智能文件管理系统，提供完整的文件管理、文档分析、用户管理和P2P文件共享功能。系统采用PyQt6构建现代化GUI界面，所有处理在本地完成，无需联网，确保数据安全。

## 核心功能

### 文件管理
- **文件导入**：支持多种文件格式的导入和管理
- **智能搜索**：基于内容和标签的快速搜索
- **文件分类**：自动和手动分类管理
- **标签管理**：为文件添加和管理标签
- **知识图谱**：可视化文件之间的关联关系

### 文档分析
- **文档内容提取**：支持PDF、Word、Excel、TXT等多种文件格式
- **智能摘要生成**：自动生成文档核心内容摘要
- **关键词提取**：基于TF-IDF和TextRank算法提取关键词
- **数据可视化**：文件类型和分类的图表展示

### 用户管理
- **用户注册**：创建新用户账号
- **用户登录**：安全的用户认证
- **角色管理**：支持不同权限角色（admin、user、viewer）
- **用户信息管理**：修改用户角色和密码

### P2P文件共享
- **设备发现**：自动发现局域网内的其他设备
- **组管理**：创建和管理文件共享组
- **文件共享**：在组内安全共享文件
- **实时同步**：保持文件的最新状态

### 系统设置
- **存储管理**：配置存储目录
- **搜索设置**：调整搜索参数
- **界面设置**：切换主题和视图模式

## 技术栈

- **前端**：PyQt6 (GUI界面)
- **后端**：Python 3.8+
- **文档处理**：
  - pdfplumber (PDF解析)
  - python-docx (Word解析)
  - openpyxl (Excel解析)
- **自然语言处理**：
  - jieba (中文分词)
  - scikit-learn (TF-IDF、相似度计算)
  - numpy (数值计算)
  - networkx (TextRank算法)
- **网络通信**：
  - socket (P2P通信)
  - threading (多线程)
- **数据存储**：
  - SQLite (本地数据存储)
  - JSON (配置和数据序列化)

## 快速开始

### 方法一：使用打包好的可执行文件

1. 从 `dist/gui_app` 目录复制整个 `gui_app` 文件夹到目标电脑
2. 双击 `gui_app.exe` 即可运行
3. 首次运行时会自动创建必要的目录结构

### 方法二：从源代码运行

1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

2. 运行应用：
   ```bash
   python gui_app.py
   ```

## 系统要求

- **操作系统**：Windows 7+ (仅支持Windows)
- **内存**：至少4GB
- **存储空间**：至少1GB可用空间
- **CPU**：至少双核处理器

## 使用指南

### 1. 首次运行

1. 启动应用程序
2. 点击"注册新账号"创建用户
3. 使用创建的账号登录
4. 开始使用系统功能

### 2. 导入文件

- 点击"文件管理"标签页
- 点击"导入文件"按钮
- 选择要导入的文件
- 系统会自动分析文件并提取信息

### 3. 搜索文件

- 点击"智能搜索"标签页
- 在搜索框中输入关键词
- 点击"搜索"按钮或按Ctrl+F
- 查看搜索结果

### 4. 共享文件

- 点击"P2P文件共享"标签页
- 在"组管理"中创建或选择一个组
- 在"文件共享"中选择要上传的文件
- 点击"上传文件"按钮

### 5. 系统设置

- 点击"系统设置"标签页
- 调整存储目录、搜索参数和界面设置
- 点击"保存设置"按钮

## 快捷键

- **Ctrl+I**：导入文件
- **Ctrl+F**：聚焦搜索框
- **F5**：刷新当前标签页
- **Ctrl+Q**：退出应用

## 故障排除

### 启动失败

- 检查系统是否为Windows 7或更高版本
- 检查是否有足够的存储空间
- 查看 `logs/app.log` 文件了解详细错误信息

### 文件导入失败

- 检查文件格式是否支持
- 检查文件是否损坏
- 检查文件路径是否包含特殊字符

### P2P连接问题

- 检查网络连接是否正常
- 检查防火墙是否阻止了应用程序
- 确保所有设备在同一局域网内
